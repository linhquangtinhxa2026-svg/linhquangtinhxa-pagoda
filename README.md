# Linh Quang Tịnh Xá

Đây là dự án website cá nhân được phát triển và xây dựng bởi **Trần Ngọc Toàn** — thương hiệu cá nhân của tôi trong lĩnh vực phát triển phần mềm.

## Về dự án

Website marketing và hệ thống quản trị cho Linh Quang Tịnh Xá, xây dựng trên nền tảng Next.js với PocketBase làm backend.

Truy cập website: https://toantrandev.com/
